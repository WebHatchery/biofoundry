# Player-facing copy audit

The stable player-facing copy for the startup menu, help overlay, field-guide
prompts, and load confirmation now lives in
[`assets/data/copy.json`](../assets/data/copy.json). `CopyDef` is the typed
schema, `GameData::message` is the lookup seam, and the table is loaded with
`macroquad_toolkit::include_json_str!` plus `DataRegistry`.

`src/data/validation.rs` checks every record for a non-empty ID and message,
requires all startup and interaction IDs in `REQUIRED_COPY_IDS`, and validates
the referenced UI/tutorial-facing copy before the game starts. The migrated
data tests also verify the complete required-ID set and representative text.

State-dependent labels and numeric status messages remain Rust-generated by
design: they combine live simulation values with typed data IDs. They are not
omitted from the audit; they are the next localization slice if those dynamic
templates need to become editable content.
